# PathFinder — Asisten Rekomendasi Jurusan & Jalur Karier Berbasis Minat

Aplikasi web responsif (dapat dibuka di HP, tablet, laptop, dan PC) yang membantu siswa memetakan kecenderungan minat dan kemampuan ke dalam 4 klaster utama:
1. **Logika & Sistem**
2. **Analisis Data & Riset**
3. **Komunikasi & Sosial**
4. **Bisnis & Ekonomi**

## Fitur Utama
- Kuis singkat 8 pertanyaan skala 1–4 dengan validasi jawaban.
- Perhitungan skor dan persentase kecocokan secara *real-time* di sisi klien.
- Rekomendasi jurusan, jalur karier, dan *roadmap* langkah awal (0–6 bulan).
- Tata letak responsif untuk layar HP maupun desktop.

## Cara Menjalankan & Mengunggah ke GitHub
1. Simpan file `index.html`, `style.css`, `script.js`, dan `README.md` dalam satu folder.
2. Kompres folder menjadi file `.zip` (opsional) lalu unggah ke repositori baru di **GitHub**.
3. Aktifkan **GitHub Pages** pada menu *Settings > Pages* (`Deploy from a branch`, pilih `main` dan `/ (root)`) agar aplikasi bisa diakses publik via tautan web di HP maupun PC.

## Catatan Keamanan & Data Simulasi
- Seluruh data pada aplikasi bersifat simulasi/edukasi.
- Tidak menggunakan *API key*, kata sandi, maupun data pribadi pengguna.
